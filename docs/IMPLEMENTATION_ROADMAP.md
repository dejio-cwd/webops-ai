# Implementation roadmap

## Release 1 — Production foundation

Next.js/TypeScript, Supabase Auth/PostgreSQL, organizations, projects, immutable audits, queue abstraction, Docker worker, object storage, logs, RBAC, and domain verification.

## Release 2 — Professional crawler

Spider/sitemap/list/hybrid modes, robots, URL normalization, prioritization, retries, pause/resume/cancel, HTTP extraction, Playwright rendering, redirects, depth, inlinks/outlinks, snapshots, and strict SSRF controls.

## Release 3 — Evidence and rule engines

SEO, links, assets, structured data, accessibility, security, content, duplicates, indexability, transparent scoring, and complete finding contracts.

## Release 4 — Performance intelligence

Lighthouse, Core Web Vitals, resource waterfalls, budgets, field-data connectors, historical comparisons, and regression attribution.

## Release 5 — Opportunity and Fix Center

Deterministic aggregation/scoring, remediation playbooks, code/config proposals, Jira/GitHub actions, approval queues, bulk fixes, re-crawl, and verification.

## Release 6 — AI Studio

Provider abstraction, dynamic model catalog, encrypted BYOK, custom endpoints, model router, tools, agents, workflows, prompt registry, structured output, usage/cost, evaluation, and provenance.

## Release 7 — Business and ecommerce intelligence

GSC, GA4, traffic/revenue impact, Magento/Shopify/WooCommerce rules, product/category intelligence, and executive reporting.

## Release 8 — Monitoring and enterprise hardening

Schedules, alerts, Slack/Teams, SSO, audit logs, retention, KMS, quotas, billing, HA workers, disaster recovery, and observability.

Each release requires automated tests, migration tests, security tests, load tests, visual QA, documented runbooks, and acceptance criteria before promotion.
